About The Project (AI Core Concepts)

Trader

What is an Expert System?

An Expert System is a computer program that uses artificial intelligence technologies to simulate the judgment and behavior of a human or an organization that has expert knowledge and experience in a particular field. In this project, it acts as a virtual stock broker that analyzes market data to provide trading recommendations.

Knowledge Base

The Knowledge Base stores both factual and heuristic information. For this trading platform, it consists of:

  • Facts: The real-time (simulated) stock data including Price, Volume, RSI, and Trend direction.
  • Rules (Heuristics): Logical conditions set by "experts" (e.g., IF Price increases AND Volume is high THEN Buy).

Inference Engine

The Inference Engine is the brain of the expert system. It applies logical rules to the knowledge base to deduce new information. It operates primarily in two modes:

  • Forward Chaining: Data-driven approach. It looks at the current stock data and checks which rules can be applied to reach a "Buy", "Sell", or "Hold" conclusion.
  • Backward Chaining: Goal-driven approach. It starts with a hypothesis (e.g., "The stock is a Buy") and looks backward through the rules to verify if the current data supports this goal.

Resolution Concept

In AI logic, resolution is a rule of inference leading to a proof by contradiction. In the context of our rule-based system, resolution occurs when the inference engine evaluates conflicting rules or multiple valid rules to arrive at a single, deterministic conclusion. For instance, if conditions for both "BUY" and "SELL" fail to be met completely, the system resolves to the default "HOLD" state to minimize risk.
